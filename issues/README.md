# Issues

Working notes on open problems. Informal, editable, disposable.

The durable record of an open question lives in `docs/0009` (the register).
This directory is for the scratch work of resolving one — command output,
half-formed reasoning, source excerpts.

When a question resolves, record the resolution in `docs/0009` and, if it
changes a decision, write a numbered DECISION document. Then the notes here
can be deleted.
